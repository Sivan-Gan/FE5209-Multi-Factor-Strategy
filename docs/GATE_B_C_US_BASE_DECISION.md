逐年净收益：

| | 2016 | 2017 | 2018 | 2019 | 2020 |
|---|---|---|---|---|---|
| 冻结配置 ra1 | 14.3% | 25.4% | −3.3% | 26.6% | 20.3% |

**理由**
1. J=26、λ=0.5 是 SSOT 事先登记的基准参数；J=26 在所有 J 中稳定最好，J=52 最差。
2. Buffer 在所有配置中都提高了净夏普，并把换手降到约 1/3。
3. 风险调整开：在 J=13、J=26 上收益、夏普、回撤、换手、交易胜率全部改善；经济含义是按因子的风险调整后动量分配权重。
4. 相对静态多因子（λ=0）和等权全样本基准，收益和风险指标都更好；对成本不敏感（成本翻倍后夏普 0.84）。

## 3. 已知局限 / 例外（Exception）

- 风险调整的优势**主要来自 2020 年**（+3.5 个百分点）；2016 年反而较差；在 J=52 上不成立。
- 配置之间的差距（夏普约 0.03–0.06）在 5 年样本的估计误差范围内；FMOM 增量尚未做 SSOT 4.9 要求的显著性检验。
- 所有配置都没有稳定跑赢市值加权标普 500，主要来自等权结构（等权全样本基准本身落后标普约 2%/年）。
- 2016 年策略明显落后等权基准（约 −10 个百分点）。
- 以上为周度口径；正式数字由 M5 用日度 NAV 复核（SSOT 4.4）。
