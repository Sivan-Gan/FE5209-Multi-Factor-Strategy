## 1b. 口径修正：FMOM 窗口规则（2026-10-13）

Gate C 首次验收（旧规则）全部 PASS，但信息项 FMOM_04 显示风险调整版本有 75 周（2016-01-08 至 2017-06-09）退回等权。排查（`scripts/find_factor_return_gaps.py`）发现 3 处因子收益缺口，每处都只是 1 只股票当周缺日收益（`MISSING_DLYRET`），CRSP 原始数据中即为 NA：

| 周 | PERMNO | 受影响因子 |
|---|---|---|
| 2015-05-08 | 76744 | 4 个全部 |
| 2015-06-05 | 76614 | 4 个全部 |
| 2020-10-30 | 76841 | Quality、Investment |

按旧规则（读法 A：最近 J / 104 个日历周必须全部有效），一只股票缺一天数据，会让风险调整 FMOM 失效两年；样本外 2020-11 至 2022-10 也会受影响。全组决定改用读法 B：每个因子取最近 J / 104 个有效周，跳过缺失周，不补任何值（符合 SSOT "不允许把缺失 factor return 填成 0"）。

**这是看到 Gate B 结果之后的口径修正**，原因是数据缺口导致的机械性失效，不是为了改善结果。修正后必须用读法 B 重跑全部 28 组配置，重新确认选择；第 2 节的数字以重跑结果为准。

**理由**
1. J=26、λ=0.5 是 SSOT 事先登记的基准参数；J=26 在所有 J 中稳定最好，J=52 最差。
2. Buffer 在所有配置中都提高了净夏普，并把换手降到约 1/3。
3. 风险调整开：读法 B 下，在**全部 6 组**（J × λ，有 Buffer）比较中都高于风险调整关；选定配置逐年 5 年全部 ≥ ra0。经济含义是按因子的风险调整后动量分配权重。
4. 相对静态多因子（λ=0）和等权全样本基准，收益和风险指标都更好；对成本不敏感（成本翻倍后夏普 0.88）；扣成本后与标普 500 基本持平。
5. 没有选夏普最高的 λ=1：差距仅 0.02，在估计误差内；λ=1 为纯 FMOM、换手高约 1/3、盈亏平衡成本更低；λ=0.5 是事先登记的基准值。
